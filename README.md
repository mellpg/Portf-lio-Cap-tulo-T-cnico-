Repositório do tema personalizado em WordPress para o site oficial do **IEEE Computer Society Student Branch Chapter** da Universidade Veiga de Almeida (UVA).

---

## 📌 Sobre o Projeto

Este projeto consiste num tema dinâmico desenvolvido para gerir e divulgar as iniciativas, eventos, publicações e projetos do capítulo estudantil da **Computer Society (IEEE UVA)**. 

O objetivo é proporcionar uma plataforma simples, moderna e responsiva para conectar estudantes, pesquisadores e entusiastas de tecnologia.

---

## 🚀 Tecnologias Utilizadas

* **WordPress**: CMS utilizado para gestão de conteúdo dinâmico.
* **PHP**: Linguagem backend utilizada na estruturação dos modelos do tema.
* **Bootstrap 5**: Framework CSS para layout responsivo e componentes dinâmicos.
* **CSS3 / HTML5**: Estilização personalizada e marcação semântica.
* **LocalWP**: Ambiente de desenvolvimento WordPress local recomendado.
